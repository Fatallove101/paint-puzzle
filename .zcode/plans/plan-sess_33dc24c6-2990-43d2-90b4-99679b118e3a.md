# 方块染色解谜游戏(Paint Puzzle)实现计划

## 项目位置与结构

在 `D:\Mini programme` 下新建项目根目录 `paint_puzzle\`:

```
paint_puzzle\
├── 策划文档.md        # 详细游戏策划文档(需求第 2 步)
├── pic\               # 图片素材目录(预留;方块为纯色绘制,若放入同名图片会优先加载)
├── snd\               # 音效目录(gen_assets.py 生成的 .wav 文件)
├── src\
│   ├── main.py        # 主代码文件(游戏入口、Game 类、主循环)
│   ├── block.py       # Block 方块类
│   ├── brush.py       # Brush 画刷类(横向/竖向、随机颜色、点击动画)
│   ├── level.py       # 关卡数据、内置关卡、程序化关卡生成器
│   └── audio.py       # 音效加载与播放
└── tools\
    └── gen_assets.py  # 用标准库 wave 合成音效到 snd\(点击/染色/失败/胜利)
```

运行方式:`.venv\Scripts\python.exe paint_puzzle\src\main.py`(环境已有 pygame-ce 2.5.8)。

## 交付物 1:策划文档(`策划文档.md`)

包含:游戏概述、核心玩法循环、操作说明(横向/竖向画刷)、通关判定(棋盘与目标图案完全一致)、步数限制与重置规则、难度曲线(棋盘尺寸 4×4 → 7×7、颜色数 3 → 6、步数随关卡收紧)、关卡系统(前 10 关内置 + 无限程序生成)、UI 布局图(左侧目标图案 + 步数信息,右侧棋盘,棋盘左侧行画刷、底部列画刷)、动画与音效清单、可调参数表。

## 交付物 2:核心代码

### 类设计(对应需求第 12-17 步的解耦)

- **Block**:位置、颜色索引;`draw()` 用纯色矩形 + 描边绘制(若 `pic/` 存在对应编号图片则优先加载);支持染色渐变动画(颜色插值,逐步染色)。
- **Brush**:`orientation`(row/col)、索引、当前颜色(随机)、`click()` 触发按压动画(缩放/位移)并发出染色请求。
- **Game**:棋盘参数化(`rows, cols, num_colors, min_steps`),状态机 `PLAYING / WIN_ANIM / RESET`,步数计数、剩余步数显示、通关检测(逐格比对目标)、胜利动画(棋盘方块波浪式跳动/闪烁)、关卡重置与下一关切换。改构造参数即可生成不同尺寸棋盘。

### 关卡与可解性保证(第 29 步)

程序化生成器从空白棋盘出发,**反向模拟**随机若干次"整行/整列染色"得到目标图案——保证每关必然可解;`min_steps` 取该生成序列长度(再留 1-2 步余量)。关卡 1-10 为手工内置参数,第 11 关起由生成器按难度曲线无限生成。

### 界面与交互(第 6-11 步)

- 鼠标点击行画刷 → 该行逐步染成画刷颜色;点击列画刷 → 该列染色;每步消耗 1 步。
- 用后画刷随机换成新颜色(从本关颜色数中随机,避免与当前相同)。
- 顶部/左侧显示:关卡号、剩余步数、重试按钮;步数耗尽 → 提示后关卡重置。
- 通关 → 胜利动画 + 音效,按任意键/点击进入下一关。

### 音效(第 22 步补充)

`tools\gen_assets.py` 一次性运行:用 `wave` + 数学函数合成 `click.wav`(短促)、`paint.wav`(扫频)、`fail.wav`(低音)、`win.wav`(上行琶音),`audio.py` 通过 pygame.mixer 播放;若 `snd/` 缺文件则静默跳过,不影响运行。
