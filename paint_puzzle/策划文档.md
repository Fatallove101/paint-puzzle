# 《方块染色解谜》(Paint Puzzle)游戏策划文档

- 版本:v2.0
- 日期:2026-09-08
- 类型:策略类方块染色解谜游戏(Python + pygame)
- 平台:Windows 桌面(960×720 窗口)

---

## 0. 界面流程与系统(自 v2.0)

```
主菜单(开始游戏 / 继续上次关卡 / 设置 / 退出游戏)
   ├─ 开始游戏 → 选择难度(简单:色板自选颜色 / 困难:随机笔刷色)
   │              → 选择关卡(第 1~10 关;第 11 关起通关后自动随机生成)
   ├─ 继续上次关卡 → 直接从存档的"难度 + 关卡"进入对局
   ├─ 设置 → 音效开关(开/关)+ 玩法说明
   └─ 退出游戏
```

- **进度存档**:进入新关卡、通关进入下一关时自动写入 `save.json`(不入 git)。
- **难度差异**:简单=先在色板选色再点画刷染色(颜色可控);困难=每支笔刷自带随机颜色、用后换新(颜色靠规划与提示)。
- **对局内快捷键**:`ESC` 保存并返回主菜单;`Ctrl+Z` 撤销上一步。
- **撤销**:可连续撤销到本关开局;重试/切换关卡/死局重置会清空撤销栈;步数耗尽后仍可撤销"挽救"。

## 1. 游戏概述

玩家面对一块空白棋盘,**先在上方色板选中一种颜色**,再点棋盘左侧的**横向画刷**(染整行)或底部的**竖向画刷**(染整列)。每关给出一个目标图案,玩家需在**限定步数内**,把棋盘染成与目标图案完全一致即通关。

核心乐趣:规划染色顺序与用色——后染的颜色会覆盖先染的颜色,玩家要像"倒推"一样思考:最后一步染什么、用什么颜色,第一步就该避开什么。

## 2. 核心玩法循环

```
查看目标图案 → 规划染色顺序 → 点击行/列画刷染色 → 步数内匹配目标?
   ↑                                              ├─ 是 → 胜利动画 → 下一关
   └────── 步数耗尽 → 关卡重置,重新挑战 ←──────────┘
```

## 3. 操作说明

| 操作 | 效果 |
|------|------|
| 点击棋盘上方色板某一色块(简单难度) | 选中当前要用的颜色(金圈高亮) |
| 点击棋盘左侧某个行画刷 | 染整行:简单=当前选中色;困难=该笔刷自带色。消耗 1 步 |
| 点击棋盘底部某个列画刷 | 染整列:简单=当前选中色;困难=该笔刷自带色。消耗 1 步 |
| 点击"提示"按钮 | 简单:色板自动选中所需颜色;困难:把目标画刷调成所需颜色。均高亮该行/列,点击即可;次数=剩余步数 |
| 点击"撤销"按钮 / Ctrl+Z | 退回上一步(棋盘、步数、笔刷颜色一并还原),可连续撤销 |
| 点击右上角"重试"按钮 | 立即重置本关(棋盘清空、步数恢复、撤销栈清空) |
| 通关后点击/按任意键 | 进入下一关(第 11 关起自动生成) |
| ESC | 保存进度并返回主菜单(主菜单再按一次退出) |
| 关闭窗口 / 主菜单"退出游戏" | 退出游戏 |

- 简单难度颜色完全由玩家选择;困难难度笔刷用后随机换新,提示可帮你把颜色设好。
- 染色不是瞬间完成:方块按从左到右 / 从上到下依次渐变染色(动画)。

## 4. 通关判定

通关条件:棋盘每一个方块的颜色与目标图案对应位置的颜色**完全一致**(空白=颜色 0)。

检测时机:每次染色动画播完、棋盘稳定后逐格比对;达成则进入 `WIN` 状态。

## 5. 步数与失败规则

- 每关设定 `min_steps`(下限步数),玩家实际可用步数 = `min_steps + 2` 的余量。
- 每次点击行/列画刷消耗 1 步;剩余步数显示在棋盘上方,低于 3 步时变红提示。
- 步数耗尽仍未通关:播放失败音效,显示"步数耗尽"提示,约 1.5 秒后关卡自动重置。

## 6. 关卡系统与难度曲线

- 第 1~10 关:手工内置参数关卡。
- 第 11 关起:由**程序化关卡生成器**无限生成;生成方式为从空白棋盘反向模拟随机染色序列,保证每关必然可解,且最优步数不大于序列长度。

| 关卡段 | 棋盘尺寸 | 颜色数 | 染色序列长度(≈步数) |
|--------|----------|--------|----------------------|
| 1~3    | 4×4      | 3      | 4~6                  |
| 4~6    | 5×5      | 4      | 6~9                  |
| 7~10   | 6×6      | 5      | 9~13                 |
| 11+    | 7×7      | 6      | 12~16,随进度缓慢加长 |

## 8. 动画清单

| 动画 | 说明 |
|------|------|
| 染色渐变 | 被染方块颜色从旧色向新色插值,按行/列顺序错峰触发 |
| 画刷点击 | 画刷被按下时缩小回弹(0.15s),伴随点击音效 |
| 色板选中 | 点击色块或提示自动选色后,该色块以金色描边高亮 |
| 胜利动画 | 棋盘方块按对角线次序波浪式弹跳、闪烁,约 1.2s |
| 失败重置 | 步数耗尽时棋盘整体闪红后清空 |

## 10. 美术方案

- 方块使用**纯色绘制**(带深色描边)。色板为精选的 26 种高饱和、高区分度颜色,按"前缀互异性"排序——每关取前 N(3~6)种,任意前缀放在一起都容易分辨,保证色准与可读性。
- `pic/` 目录为预留位:若放入 `block_0.png ~ block_26.png`,游戏会优先加载图片作为方块贴图,否则回退纯色绘制。
- 画刷使用圆角矩形 + **中性底色 + 方向箭头**(行刷箭头向右、列刷箭头向下),本身不带颜色;颜色由玩家在色板上方自行选择。

## 11. 提示功能设计

- 顶栏"提示 ×N"按钮:**可用次数 = 当前剩余步数**(每走一步都能要一次提示,不单独扣减),用完置灰。
- **通关保证**:提示基于当前棋盘实时计算"还缺的下一步",只要从本关开局(棋盘全空)就跟随提示点击,必能在剩余步数内通关;内置关与第 11 关起的程序生成关均保证,并由 `tools/smoke_test.py` 自动化验证(第 1~25 关)。
- 算法(**反推求解器**):最后染的线在目标图上必为单色,不断"剥"掉这类单色线即可倒推出完整解法;玩家中途的无害操作会被求解器自动跳过。
- 提示时:计算当前局面下还需要的下一步(染哪一行/列 + 所需颜色)→ **在色板中自动选中该颜色(不改变任何画刷)** → 目标画刷卡白脉动描边、棋盘对应行/列覆盖脉动高亮、底部显示"提示:点击第 X 行/列画刷(颜色已自动选好)",持续 4 秒。玩家也可不跟提示,自行点击色板换色后落子。
- **死局兜底**:若玩家把本应留白的格子染了色,棋盘会变成不可还原的"死局"(空白无法再被涂回)。此时点提示会提示"当前局面已无法达成目标,即将自动重试…",约 1.4 秒后自动重置本关,无需手动点重试。

## 12. 可调参数表(`main.py` 顶部常量)

| 参数 | 默认值 | 说明 |
|------|--------|------|
| CELL_SIZE | 64 | 方块边长(像素) |
| FPS | 60 | 帧率 |
| STEP_MARGIN | 2 | 步数余量(在最优步数上额外赠送) |
| PAINT_DELAY_MS | 40 | 相邻方块染色的错峰间隔 |
| 提示次数 | = 剩余步数 | 每步都可要一次提示,不单独扣减;跟随提示必通关 |
| HINT_SHOW_SEC | 4.0 | 提示高亮与文案显示时长 |
| GAME_COLORS | 26 色 | 精选高区分度色板(按前缀互异性排序) |
| 内置关卡表 levels | 10 组 | (rows, cols, colors, seq_len) 参数 |

## 13. 代码结构

```
src/
├── main.py    # 入口 + Game 类(状态机:PLAYING / WIN / RESET)
├── block.py   # Block 方块类(颜色、插值动画、绘制,图片优先加载)
├── brush.py   # Brush 画刷类(方向、随机换色、按压动画)
├── level.py   # 内置关卡 + LevelGenerator(反向模拟保证可解)+ 反推求解器
└── audio.py   # 音效加载与播放(snd/ 缺文件时静默跳过)
```
